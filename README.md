# Cybersecurity Incident & Hygiene Guide

## Project Overview
This repository provides standard operational templates for Security Operations Center (SOC) incident handling and an employee baseline cybersecurity checklist.

## Repository Contents
* `README.md` - Overview and documentation guide.
* `security_checklist.md` - Core cyber hygiene practices for staff.
* `incident_report_template.md` - Incident reporting form for security events.

## Incident Escalation
For urgent security incidents, contact the Zulu Global SOC team at `soc-helpdesk@zuluglobal.com`.
