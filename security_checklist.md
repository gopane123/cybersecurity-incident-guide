# Employee Cybersecurity Hygiene Checklist

### 1. Authentication & Access
- [ ] Enable Multi-Factor Authentication (MFA) on all corporate accounts.
- [ ] Use passwords with a minimum length of 14 characters combining uppercase, numbers, and symbols.
- [ ] Never share or reuse credentials across different platforms.

### 2. Phishing & Email Security
- [ ] Verify external email senders before opening links or attachments.
- [ ] Inspect destination URLs by hovering over embedded hyperlinks.
- [ ] Report suspicious phishing emails directly to the SOC team.

### 3. Workstation Security
- [ ] Lock screen (`Win + L`) when leaving your workstation unattended.
- [ ] Maintain updated anti-malware software and operating system patches.
